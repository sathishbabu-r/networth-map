# Networth MAP + Money Huddle

Approved on 3 October 2026. This extends the original first-session scope.

- Desktop: Networth MAP uses 70% on the left; conversational Money Huddle uses 30% on the right. On smaller screens both remain reachable.
- Start with the user’s concern, give useful formula-based observations early, then guide completion of Earn, Own, Owe, Spend, Invest, Lifestyle, Goals and Milestone.
- Exact original buildweek Networth MAP: all twelve screens, colours, Cochin and Playfair typography, content, input choices, validations, financial calculations, findings, action assessments, sharing and print output. Reuse original source rather than a simplified replacement.
- The authenticated account replaces the original device-only save. Privacy copy must reflect this. Chat does not invent missing inputs or treat unknown amounts as zero.
- Preserve feedback and optional email collection in Convex. Original external email notifications require separate approval under the project’s service restriction.
- Remember answers between visits automatically. Correct them through conversation.
- Return by following up on the last action, while allowing a new concern. One active dated action; completed actions and reported results remain in history.
- Daily progress separates action completion, realised outcomes and explicitly reported balance updates. No automatic financial improvement from a completed action; no automatic balance reduction from an outcome.
- Convex remains the database, authentication and hosting. No changes to /Users/admin/buildweek.
- No bank links, reminders, investment recommendations or autonomous decisions.
